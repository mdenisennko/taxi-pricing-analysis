# Анализ ценообразования на рынке такси

## О проекте

Проект посвящен исследованию факторов, связанных со стоимостью поездок на такси.

Датасет содержит **7 131 наблюдение**.

## Цель

Определить, какие факторы сильнее всего связаны со стоимостью поездки, и проверить статистическую значимость их влияния.

## Этапы анализа

1. Очистка и подготовка данных
2. Исследовательский анализ данных
3. Визуализация
4. Кодирование категориальных признаков
5. Построение OLS-регрессии
6. Проверка статистических гипотез
7. Сравнение моделей

## Основные результаты

- расстояние и уровень спроса оказались основными предикторами стоимости;
- итоговая модель имеет **R² = 0,95**;
- исследовано влияние погоды, времени суток и других факторов;
- проведено сравнение моделей с учетом спроса и без него.
